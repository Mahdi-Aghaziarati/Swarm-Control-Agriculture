# Module (B)
## Module Structure

| Folder | Description |
|--------|-------------|
| `Fire Detection/` | Fire detection in fields using camera imagery |
| `Pest Detection/` | Identification of agricultural pests on crops |
| `Thermal Detection/` | Thermal image processing for temperature and crop stress monitoring |
| `YOLO/` | Models and code for training/running YOLO object detection |

## Subsystem Overview

- **Fire Detection:** Uses computer vision models to detect flames in aerial imagery, enabling rapid fire alerts.
- **Pest Detection:** Detects common crop pests in drone imagery to enable targeted pesticide spraying.
- **Thermal Detection:** Uses a thermal camera to identify hot spots, water stress, and plant health status.
